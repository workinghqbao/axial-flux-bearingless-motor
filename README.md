# Axial-Flux Bearingless Motor

A project-based learning journey focused on designing, building, and improving an axial-flux bearingless motor.

The project applies knowledge from mathematics, physics, electronics, control, embedded systems, and machine learning step by step, while documenting the learning process, experiments, and discoveries along the way.

The ultimate goal is to build a functional motor prototype and continuously improve its performance.

Learning Approach

The project follows a project-based learning approach:

Learn → Apply → Build → Measure → Improve

Each stage is accompanied by notes, experiments, problem-solving, and documentation of what is learned throughout the process.
