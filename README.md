# axial-flux-bearingless-motor
personal learning and researching motor project combine axial, bearing less, machine learning feature
A project-based learning journey focused on designing, building, and improving an axial-flux bearingless motor. It combines step-by-step application of mathematics, physics, electronics, control, embedded systems, and machine learning with ongoing documentation of the learning process, experiments, and discoveries. The ultimate goal is to build a functional motor prototype and continuously improve its performance.
